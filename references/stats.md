## Rules for using stats in copy

1. **Always specific, never round.** "47 yoga mats" not "around 50". "6 weeks of testing" not "several weeks".
2. **Always sourced.** If the number is yours, this file is the source. If the number is industry, the source URL above is.
3. **Always current.** If a stat is more than 90 days old and could've changed, refresh before quoting.
4. **Never extrapolate.** If you've tested 3 mats, you cannot say "of the mats I've tested" implying a larger sample. Say "all three mats I've tested".
5. **When uncertain, omit.** A paragraph without a number is fine. A paragraph with a fabricated number is never fine.
