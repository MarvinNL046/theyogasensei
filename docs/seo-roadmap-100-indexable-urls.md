## Mandatory page gate

A candidate becomes indexable only when it has:

- current DataForSEO metrics and a live SERP/intent brief;
- a documented primary keyword and no competing primary in `used-keywords.md`;
- complete English copy that passes the voice and content-quality checklists;
- the appropriate reviewer and authoritative citations for instructional or health-adjacent content;
- a useful visual asset rhythm of roughly one image, diagram, table or other editorial asset per 600 words;
- canonical, metadata, visible breadcrumbs, valid matching schema and 3–5 contextual internal links;
- a successful production build and a prerendered HTML output;
- no `noindex` directive and a confirmed sitemap entry.
